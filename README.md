# 🎵 Sistema de Biblioteca Musical

## 📌 Sobre o projeto

O Sistema de Biblioteca Musical é um projeto desenvolvido com o objetivo de organizar e facilitar o gerenciamento de músicas e artistas.

O sistema possui uma tela de login e um menu principal para acessar as funcionalidades da biblioteca.

## 🚀 Funcionalidades

- **Login:** acesso ao sistema por meio de usuário e senha.
- **Menu principal:** acesso às opções disponíveis.
- **Listagem de músicas:** visualização das músicas cadastradas.
- **Cadastro de músicas:** permite adicionar novas músicas.
- **Cadastro de artistas:** permite cadastrar novos artistas.
- **Filtros:** busca de músicas por título, artista e gênero.
